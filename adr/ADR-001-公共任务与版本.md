# ADR-001 公共任务模型与版本

状态：本次 B04 材料采用 A04 1.0.0 基准；实际配对沟通记录待填写。

责任人：B04 刘明轩。依据：A04 create-request、create-response、job Schema 及其两份 ADR。

## 背景

四个服务由 A04、B04 分别负责，需要使用同一份请求与结果。任务可能耗时较长，检测发现和系统执行失败也需要分开表达。

## 决定

沿用 A04 异步 Job：创建返回 HTTP 202、job_id 和 QUEUED，再通过 GET 查询。采用共同的六种状态及错误结构。正常发现 MD/RD 不改变任务成功完成的含义。

统一 schema_version 为1.0.0，使用 Draft 2020-12。沿用 A04 的字段名、必填项和各对象附加字段限制，停止使用 B04 旧0.1.0草案。

字段变化先通知配对组，同步修改 Schema、样例和决策记录。沿用 A04 版本策略：双方验证后的兼容新增提升 minor，删除、改名、改语义或状态枚举变化提升 major。旧版本严格消费者仍可能拒绝新增字段，不能直接混用新旧文件。

## 备选方案

同步执行流程简单，但可能超过 HTTP 生命周期。各组保留独立格式会增加联调映射和歧义。沿用 A04 已有契约可以直接对照同一套文件。

## 影响

后续实现需要任务存储与查询能力；E2 仅交付契约。B04 服务负责人需要遵守既有字段，不能随意添加字段。幂等冲突、有效期和部分 HTTP 错误正文待双方补充。
